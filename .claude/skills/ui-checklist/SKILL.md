# ui-checklist

코딩이 끝난 후 수동으로 무엇을 테스트해야 하는지 체크리스트를 생성합니다.

## 실행 방법

`ui-checklist` 서브에이전트에 아래 작업을 위임합니다.

```
최근 코드 변경사항(미커밋 또는 최근 커밋)을 분석해
RefPMS UI 수동 테스트 체크리스트를 한국어로 생성해줘.
```

Agent 도구를 사용해 `subagent_type: "ui-checklist"`로 위임하고,
에이전트가 반환한 체크리스트를 그대로 사용자에게 출력합니다.
추가 설명이나 서문 없이 체크리스트만 출력합니다.
